# 🏀 Basketball Tracking Analytics

Полностью автономное (офлайн) desktop-приложение на Python с графическим
интерфейсом [Streamlit](https://streamlit.io/) для аналитики баскетбольных
тренировок по видео со статичной камеры.

Приложение детектирует и трекает игроков и мяч моделью **YOLO11x**
(Ultralytics) с трекером **ByteTrack**, векторно определяет голы по пересечению
траектории мяча с горизонтальной линией кольца, детектирует передачи между
игроками, автоматически нарезает короткие MP4-хайлайты этих моментов и
показывает итоговую статистику (Box Score) прямо в интерфейсе.

Игроки в тренировочной форме **без номеров на майках** — удержание ID при
трекинге обеспечивает ByteTrack (без ReID/OCR номеров).

## Возможности

- Пошаговый мастер из 4 шагов: загрузка видео → превью и настройка зон/порогов
  → сопоставление игроков (ID → имя/номер) → полный анализ и статистика.
- Настройка **двух** горизонтальных линий колец кликом мышки по превью-кадру
  (через `streamlit-image-coordinates`) — либо точная донастройка числовыми
  полями, если пакет недоступен.
- Трекинг игроков (`person`) и мяча (`sports ball`) моделью YOLO11x на GPU
  (CUDA) с трекером ByteTrack (`track_buffer=180`, `track_low_thresh=0.1`).
- Детекция с `conf=0.15`, `iou=0.45` по умолчанию — лучше замечает удалённых
  игроков; раздельные слайдеры `person_conf`/`ball_conf`/`imgsz` остаются как
  UI-оверрайды.
- **Авто-калибровка порога владения мячом** под масштаб конкретного видео.
- Пороги владения мячом, окно передачи (в кадрах), «память» мяча и кулдаун
  гола — настраиваются слайдерами в GUI.
- Отрисовка траектории мяча (последние 10 точек) на аннотированном видео и
  хайлайтах.
- Опциональное улучшение качества кадра перед детекцией (апскейл + резкость).
- **Диагностика видимости мяча** (шаг 3).
- **Экспериментальный режим «камера в движении» (панорама)**.
- **Векторная детекция голов**: пересечение отрезка движения мяча с
  горизонтальной линией кольца сверху вниз, кулдаун 90 кадров.
- **Детекция передач**: владелец → мяч без владельца 10–60 кадров → новый
  владелец; +1 пас предыдущему владельцу.
- Отладочный таймлайн владения мячом (expander на шаге 4).
- Ручное сопоставление ID игрока → Имя/Номер по кропам предварительного
  сканирования.
- Автоматическая нарезка MP4-хайлайтов и перекодировка в H.264 через ffmpeg.
- Работает полностью офлайн после первого запуска.

## Структура репозитория

```
.
├── app.py                  # Всё приложение (Streamlit GUI + логика трекинга/аналитики)
├── requirements.txt        # Python-зависимости с версиями
├── custom_bytetrack.yaml   # Конфиг трекера (генерируется автоматически при первом запуске)
├── highlights/             # Нарезанные MP4-хайлайты (авто-создаётся)
├── output_videos/          # Полные аннотированные видео (авто-создаётся)
└── README.md
```

`custom_bytetrack.yaml`, `highlights/` и `output_videos/` **не нужно создавать
руками** — `app.py` создаёт их автоматически при первом запуске.

## Требования к железу и ПО

- Python 3.10–3.12.
- Рекомендуется NVIDIA GPU с CUDA (протестировано для **RTX 4080**).
- Интернет нужен **только один раз** — для скачивания весов YOLO11x.
- **ffmpeg (рекомендуется)** — для H.264-перекодировки выходного видео.

## Установка (Windows/Linux, RTX 4080)

1. Создайте и активируйте виртуальное окружение:

   ```bash
   python -m venv .venv
   # Windows:
   .venv\Scripts\activate
   # Linux/macOS:
   source .venv/bin/activate
   ```

2. Установите CUDA-версию PyTorch (см. https://pytorch.org/get-started/locally/):

   ```bash
   pip install torch==2.4.1 torchvision==0.19.1 --index-url https://download.pytorch.org/whl/cu124
   ```

3. Установите остальные зависимости:

   ```bash
   pip install -r requirements.txt
   ```

4. Запустите приложение:

   ```bash
   streamlit run app.py
   ```

## Как пользоваться (пошаговый мастер)

**Шаг 1** — режим камеры и загрузка видео.

**Шаг 2** — превью и настройка:
   - Клик по превью задаёт центр (X) и Y **горизонтальной линии** кольца;
     полуширина линии настраивается числовым полем.
   - Порог владения мячом (дефолт 90 px), окно паса (10–60 кадров без
     владельца), кулдаун гола (90 кадров), пороги conf/imgsz.

**Шаг 3** — сопоставление игроков и диагностика мяча.

**Шаг 4** — полный анализ, Box Score, хайлайты, отладочный таймлайн.

## Как это работает (логика аналитики)

- **Трекинг ByteTrack.** Конфиг `custom_bytetrack.yaml`: `tracker_type:
  bytetrack`, `track_buffer: 180` (~5–6 сек при 30 fps), `track_low_thresh: 0.1`.
  ReID/BoT-SORT не используется.
- **Детекция.** `model.track()` с `conf=0.15`, `iou=0.45` (дефолты);
  слайдеры `person_conf`/`ball_conf` — UI-оверрайды; постфактум-фильтрация по
  классам в `parse_track_results`.
- **Владение мячом.** Центр мяча в пределах `possession_threshold` px от bbox
  игрока (дефолт 90).
- **Передача.** Игрок_1 владел → мяч без владельца 10–60 кадров → Игрок_2
  получил владение → +1 пас Игроку_1.
- **Гол.** Пересечение отрезка `(x_prev,y_prev)→(x_curr,y_curr)` с
  горизонтальной линией кольца сверху вниз; автор — последний владелец мяча;
  кулдаун 90 кадров на кольцо.
- **Траектория мяча.** На аннотированном видео рисуется линия по последним 10
  координатам мяча (яркий жёлтый цвет).
- **Хайлайты.** 5 сек «до» + 2 сек «после» события.
